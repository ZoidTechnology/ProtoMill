# ProtoMill

Produce custom two-layer PCBs from KiCad designs in minutes using a low-cost CNC machine. ProtoMill guides you from importing a design to milling your PCB. Pre-manufactured substrates reduce milling time and provide plated through-holes without additional processing.

## Requirements

- Windows 10+ or macOS 13+
- KiCad 10+
- CNC machine running Grbl 1.1+
- ProtoMill fixture and substrate

## Usage

1. Download the ProtoMill application and KiCad libraries.
2. Use the provided libraries to design your PCB in KiCad. Ensure the KiCad API is enabled.
3. Install the ProtoMill fixture on your CNC machine and connect the machine to your computer.
4. Launch the ProtoMill application and follow the instructions to mill your PCB.
